# SVGs da marca — Magneira Consultoria

Arquivos gerados:

- `magneira-logo-vertical.svg`
- `magneira-logo-horizontal.svg`
- `magneira-logo-icon.svg`

## Características

- arquivos SVG editáveis;
- fundo transparente;
- cores baseadas no guia da marca;
- tipografia configurada como texto editável;
- estrutura organizada em grupos (`<g>`) para facilitar ajustes.

## Cores usadas

- Azul Profundo: `#0B3D91`
- Azul Petróleo: `#0E5F78`
- Turquesa Tech: `#17B6C6`
- Cinza Claro: `#A7B2BF`

## Fontes referenciadas

- `Michroma` para o nome MAGNEIRA
- `Montserrat` para “Consultoria”

> Observação: se a máquina não tiver essas fontes instaladas, o SVG usará as fontes de fallback definidas no arquivo.
